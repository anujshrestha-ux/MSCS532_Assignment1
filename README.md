# MSCS532 Assignment 1

Insertion Sort implemented in Python that sorts an array in monotonically decreasing order.

## How to run

```
py insertion_sort.py
```

## Example

Input: `[5, 2, 4, 6, 1, 3]`
Output: `[6, 5, 4, 3, 2, 1]`

## How it works

Based on Insertion Sort from Chapter 2 of *Introduction to Algorithms* (Cormen et al., 2022). The only change from the textbook version is the comparison in the while loop (`<` instead of `>`), which produces decreasing order.
